# Как устроен FileSentinel

Снимок — это отсортированное отображение относительных путей в размер и SHA-256.
Два снимка сравниваются как множества путей, затем сравниваются записи общих
файлов. Изменение содержимого выявляется даже при одинаковом размере.

Хеширование идёт потоком, без загрузки файла целиком в память. Перед чтением,
через открытый дескриптор и после чтения проверяется идентичность и состояние
файла. На Windows ctime из lstat и fstat может иметь разную семантику, поэтому
оно сравнивается только между наблюдениями одного типа.

Для собеседования: почему SHA-256 не подтверждает автора baseline, чем хеш
отличается от подписи, что такое TOCTOU и почему последовательный обход дерева
не равен атомарному снимку файловой системы. Возможный следующий этап —
детерминированный экспорт и отдельно спроектированная подпись baseline.
